# Verdict

How the reading is: five dots and a word, on one scale shared by every instrument.

- Good uses the instrument's own accent (`nominal` in Break, `phosphor` in Trace). Fair is `ochre`, poor is `clay`, idle dots are `sand`.
- The word is label mono at 12px, weight 500, in the same color as its dots. The dot count carries the meaning, so it never rests on hue alone.
- The live dot (6px, accent) is the only thing in the system that loops: a slow opacity pulse, nothing else.
- Progress is a row of 2px ticks: accent for done, `sand` for remaining.

The consumer provides the level (good, fair, poor), the dot count and the word.
