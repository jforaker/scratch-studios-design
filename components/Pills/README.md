# Pills

A row of places to pick from. Fully round, 38px tall, 13px Barlow 500 in tracked caps (`place`).

- The selected pill sits on the instrument's `*-selection` ground with `ink` text and no outline, the same ground shift as a selected row. Never an accent fill.
- Unselected pills are outlined in `rule-strong`.
- The place name above uses tracked caps; its region sits under it in label mono.

The consumer provides the places and the selected one.
