# SettingsRow

One setting per row: the name (and an optional description) on the left, the control on the right, rows divided by full `rule` hairlines.

- Name in Barlow 14px 500; description in `small` and `ink-soft`, as a full sentence.
- Segmented controls sit in a `track` with a `rule-strong` outline; the chosen segment is on `raised`.
- Steppers and menus are outlined in `rule-strong` at `radius-md`. Values in label mono.
- Changes apply immediately. There is no Save button.

The consumer provides the setting, its options and the current value.
